# 🖤 LojaRoupa — Landing Page

> Landing page moderna para uma marca de roupas, desenvolvida com foco em **identidade visual, apresentação de produtos e conversão de clientes através do WhatsApp**.

![LojaRoupa](foto1.1.png)

## 📌 Sobre o projeto

A **LojaRoupa** é uma landing page desenvolvida para uma marca de roupas com uma proposta visual **moderna, jovem e urbana**.

O projeto foi pensado para apresentar os produtos de forma atrativa e conduzir o visitante até o principal objetivo da página: **entrar em contato com a loja pelo WhatsApp para realizar a compra**.

Diferente de um e-commerce tradicional, a aplicação não possui checkout ou sistema de pagamento integrado. O processo de compra é direcionado para uma conversa no WhatsApp.

---

## 🎯 Objetivo

O principal objetivo da landing page é transformar visitantes em potenciais clientes através de uma experiência simples:

**Conhecer a marca → Ver os produtos → Se interessar → Entrar em contato → Comprar pelo WhatsApp.**

A interface foi construída para reduzir etapas desnecessárias e facilitar a conversão.

## 💬 Conversão pelo WhatsApp

Um dos principais objetivos do projeto é facilitar o contato entre cliente e loja.

Ao demonstrar interesse em um produto, o visitante pode utilizar os botões de **WhatsApp** disponíveis na página e iniciar diretamente uma conversa com a loja.

### Fluxo de conversão

```text
Visitante
   ↓
Conhece a marca
   ↓
Visualiza os produtos
   ↓
Escolhe um produto
   ↓
Clica no WhatsApp
   ↓
Conversa com a loja
   ↓
Compra
```

Essa abordagem mantém o processo de compra simples e adequado para uma loja que realiza seus atendimentos diretamente pelo WhatsApp.

## 🎨 Design

A identidade visual foi desenvolvida pensando em um público **jovem e conectado à moda urbana**.

A interface utiliza:

- Layout moderno;
- Tipografia marcante;
- Fotografias dos produtos;
- Seções com forte impacto visual;
- Elementos de CTA;
- Destaque para o WhatsApp;

## 🚀 Como executar o projeto

### 1. Clone o repositório

```bash
git clone https://github.com/seu-usuario/LojaRoupa.git
```

### 2. Acesse o projeto

```bash
cd LojaRoupa
```

### 3. Instale as dependências

```bash
npm install
```

### 4. Execute o projeto

```bash
npm run dev
```

A aplicação ficará disponível em:

```text
http://localhost:3000
```
